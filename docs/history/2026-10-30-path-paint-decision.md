## Executable proof

Serve `/path-paint-proof/` with the command below. It pairs public Motion with isolated CSS paint for 22 representatives and retains WindArrowDown as a complete Motion control. The existing comparison controls provide paired play/stop and native mouse row hover. The two check buttons rerun saved-pose comparisons and template/cleanup probes.

The [experiment plans](../../tests/helpers/path-paint-proof-plans.json) are frozen native-effect transcripts normalized to source length coefficients. They supply 88 paint candidates, with 513 entry property tracks. They are not maintained production recipe definitions. Their baseline timing records were copied from native effects; the interrupted/completed snapshots were saved independently and are not generated by the prototype. Production extraction remains future work and must compare its source values separately.

The prototype compiler generates sparse per-property CSS keyframes. A target-local measured length and captured first-value variables parameterize those sheets. The adapter reuses the existing track protocol and lifecycle. It applies global easing to the native effect through updateTiming, while retaining each keyframe's interval easing. Neither the shared transform engine nor the existing opacity engine changes.

WindArrowDown's complete recipe cannot use this paint-only adapter. Its final paths retain a sampled Y pose and opacity with until-clear replay and a 350 ms delay. It remains Motion in both the comparison and standalone delivery forecast. A later complete migration needs a separately proved composition adapter and a linked rollout follow-up if it remains blocked. The paint experiment does not discard that behavior.

## Browser comparisons and cleanup

The [compact proof result](2026-10-30-path-paint-browser.json) records Chrome 154 on macOS. All 7816 poses match the saved baseline across 40096 shapes, with zero failures. Maximum observed dash-list, signed-offset, opacity and matrix-component errors are zero at the recorded points. WindArrowDown is a retained Motion control; the result does not certify its migration.

The criteria preserve matrix components and translation at 0.005 and opacity at 0.001. The ADR proposes an additional absolute 0.005 SVG user-unit bound for each dash-list component and signed offset. List length, unit equivalence and the none state are checked. Unit/list/sign regressions have focused negative tests. These numerical bounds provide no owner visual acceptance.

Entry samples include 0, 1, 5, 31, 83, 199, 299, 399 and 501 ms, each recipe's midpoint and its final two times. Stop and replay interrupt entry at 31 ms, 199 ms and one millisecond before its latest delayed track ends. New tracks are sampled at 0, 1, 5, 31, 83 and 199 ms and their final two times. Repeated stop and replay during return use a 199 ms entry and an 83 ms return. Separate cases check actual completion callbacks, replay after completion, stop after hold and cleanup. The baseline JSON preserves every concrete sample time.

The [cleanup result](2026-10-30-path-paint-cleanup.json) has 726 passing checks. It covers independent templates, source-removed clones before registration, stylesheet recovery, late-sheet reconciliation, disconnect/reconnect, captured-variable cleanup and reduced motion through a synthetic matchMedia preference. The clone check manually registers the existing lifecycle with the isolated adapter; it does not claim production registration/discovery coverage for an unimplemented capability.

The [native media result](2026-10-30-path-paint-native-media.json) separately records DevTools media emulation with real matchMedia change events. All 88 CSS instances clean their animations, paint state and variables under reduction, reject playback while reduced and play after no-preference returns. This is browser media emulation, not an operating-system preference change.

The [native pointer result](2026-10-30-path-paint-native-pointer.json) covers mouse enter/leave on the 14 px AtSign row. Both events report isTrusted true and pointerType mouse. Both engines hold their matching full dash pose after entry and remove it after return. Other recipes' paused/manual and synthetic checks are not native input evidence.

The [geometry result](2026-10-30-path-paint-geometry.json) instruments one 24 px entry and return on each side of all 23 representative pairs. Across the 46 entries it records 116 length reads. Each measured target is read once per playback, and opacity-only targets read none. The output includes coarse preparation/geometry times in milliseconds, with instrumentation and no warmup. It establishes no timing advantage or frame-pacing result.

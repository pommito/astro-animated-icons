# CSS animation pilot

The [CSS playback parity follow-up](2026-10-23-css-parity.md) supersedes the active implementation described here. This record preserves the first experiment and its measurements.

Recorded on 2026-10-23, starting at commit ee11db863fee0d9fcde04a31c794cc9316d536e7. This is a limited experiment on Bell, ChevronRight, and LoaderCircle. The public exports and Motion recipes remain available. Experimental imports live under `packages/animated-icons/src/experimental/css-pilot/astro.ts` and are not package exports.

## Decision

Restrict further work to finite transform cycles such as chevrons and Bell. The byte savings justify a follow-up that preserves interrupted playback. The current CSS-only experiment changes input and return behavior, so it cannot replace the common API. Keep LoaderCircle on the existing implementation until a separate design decision addresses its velocity-aware spring and interrupted replay. Do not migrate the catalogue from this result.

## Existing behavior and required preservation

The source of these observations is the current implementation, especially [element.ts](../../packages/animated-icons/src/element.ts), [svg-keyframes.ts](../../packages/animated-icons/src/shared/svg-keyframes.ts), [chevron.ts](../../packages/animated-icons/src/shared/chevron.ts), [svg-transform.ts](../../packages/animated-icons/src/shared/svg-transform.ts), and [svg-parts.ts](../../packages/animated-icons/src/shared/svg-parts.ts). Browser checks below cover a smaller set of assertions.

| Behavior | Bell | ChevronRight | LoaderCircle |
| --- | --- | --- | --- |
| Entry | SVG rotation 0, -10, 10, -10, 0 degrees, 500 ms, easeInOut between values | Path X translation 0, 2, 0 viewBox units, 500 ms, offsets 0, .4, 1, easeOut per segment | Path rotation 0 to 360 degrees, 800 ms, linear, infinite |
| Completion | Hold final pose, which is rest | Restore and clear transform | Continue until stopped |
| Stop or pointer exit | Return from current pose to zero over 500 ms, easeInOut | Return from current pose to zero over 500 ms, easeOut | Spring to zero, stiffness 50, damping 10, mass 1, inherited interrupted velocity |
| Replay while active | Replace first entry value with retained pose | Restart the entry cycle at zero | Complete a new 800 ms segment from the retained pose to 360, then reset and resume the infinite cycle |
| Cancellation | Stop and cancel old tracks before new playback; stale completion cannot clear newer playback | Same shared lifecycle | Same lifecycle, retaining cycle-end angle and velocity for spring return |

All three use the nearest containing native link or button for pointer entry and exit. A standalone wrapper is its own trigger. Pointer entry ignores touch, controlled mode, disabled controls, aria-disabled=true, and reduced motion. Keyboard focus does not start playback. A mouse still works when touch is the primary input. Manual start does not check the disabled state of a parent. It is available regardless of the controlled prop.

The public handle methods return void. startAnimation() starts or replays the recipe when connected and motion is allowed. stopAnimation() returns an active recipe toward rest. Disconnect cancels and clears playback, reconnect finds the current parent control, and switching to reduced motion cancels and restores the drawing. These behaviors require preservation before a replacement can ship.

## Experimental differences

The automatic variant renders complete SVG and selective external CSS with no client JavaScript. CSS owns finite cycles or the infinite loader. Leaving hover removes the animation immediately. Re-entry starts at frame zero. The finite cycles run once per hover entry. The loader loops while hovered. There are no handle methods or registration promise, and setting controlled leaves this variant static.

Automatic hover requires a primary fine pointer with hover support. This loses the documented mouse behavior on devices whose primary pointer is touch. CSS also cannot distinguish a touch-created hover from mouse hover on a hybrid device. Disabled native controls and aria-disabled controls have selectors that suppress automatic playback. Focus alone has no trigger. The reduced-motion media query removes animation and restores rest. Hardware touch, hybrid behavior, and live reduced-motion changes remain unverified.

The managed variant registers one internal custom element and reuses the production lifecycle. It supports the same handle signatures, pointer filtering, controlled mode, reconnection, cancellation ordering, and reduced-motion listener. CSS starts the entry cycle; getAnimations() supplies the native animation to the existing track protocol. A forced style resolution restarts the CSS cycle on manual replay. Stop captures the rendered matrix and creates a native WAAPI return over 500 ms. Bell uses easeInOut and the other icons use easeOut.

Managed Bell restarts at zero when interrupted, unlike the retained-pose entry in the current recipe. ChevronRight has the same entry restart policy as the current recipe, but retains a finished CSS animation until stop or replay instead of clearing it on completion. The managed loader also restarts at zero. Its return interpolates a matrix to rest with a fixed duration, which can choose a different direction after half a turn. It does not preserve angular velocity, cycle-end angle, or the spring. These differences are isolated in the experiment and stated on its comparison page.

## Loading and maintenance

The original bundle assertions still require registration scripts and exactly shared CSS on production routes. The experiment has a separate validator. It checks zero scripts on automatic routes, unchanged SVG output, selective keyframes, stylesheet deduplication, repeated-instance JS reuse, a managed JS budget, and the exact unchanged Motion chunk set on the mixed automatic route. Negative tests inject an unwanted script, unused loader keyframes, and changed drawing geometry.

Each CSS file is imported as a URL rather than an Astro style block. The server adapter emits a link only for a rendered kind and uses a request-local Set to deduplicate it. The experimental barrel exports every variant, and single-icon fixture routes import through that barrel. Unused style assets can exist in dist, but their links do not appear on the page and the browser does not request them. This avoids the CSS accumulation that normal per-component Astro style blocks can cause. The strategy adds an external stylesheet request per rendered kind; weigh that latency against a future shared or generated stylesheet strategy.

Both implementations share Drawing.astro components extracted from the original adapters. Existing drawing baselines remain unchanged. The managed experiment reuses the lifecycle instead of copying its listeners, but maintains separate CSS timing data and return code. A catalogue migration would need a single recipe source or generation step to keep CSS and reference timing synchronized. Reimplementing the loader's physics would add a second spring implementation. These costs support restricting the next experiment to finite cycles.

## Browser evidence and limits

The comparison at /css-pilot/ renders the current package beside both experiments at 14, 16, 24, and 28 px. Its manual controls play, stop, and seek the current package and managed samples together. It links the existing pinned upstream comparisons, whose references remain unchanged.

In the ChatGPT in-app Chromium 155 browser, all eight synthetic lifecycle checks passed. They establish touch-event filtering, parent mouse entry, disconnect cleanup, disabled-parent filtering, controlled-hover filtering, the void handle results, and manual start. Actual mouse entry also started Bell and ChevronRight with 500 ms single iterations and LoaderCircle with an 800 ms running animation. Leaving the loader produced zero animations. JSON serialized the infinite iteration count as null. The final page had no captured console errors. Synthetic pointer events do not establish real touch behavior. [Browser evidence](2026-10-23-css-pilot-browser.json) records the results and pending checks.

One exploratory preparation run measured synchronous startAnimation() work on 20 controlled Bell instances. It alternated modes over five warmup batches and 30 measured batches per mode. Disconnect and reconnect cleanup occurred outside the timed interval. Motion's median was 2.1 ms and p95 3.6 ms. Managed CSS's median was 2.3 ms and p95 4.0 ms, including its forced style resolution. This run establishes no preparation advantage for managed CSS. It excludes rendering, compositor work, frame pacing, startup parsing, and network transfer. CSS-only hover has no JavaScript start method to compare with this test. No smoother-animation claim follows from the byte savings. The current transform mechanism already prepares sampled frames for native Motion mini playback.

Visual acceptance remains pending with the user. Real touch, hybrid input, Safari, Firefox, reduced-motion emulation, and preference changes during playback remain unverified. The Chrome DevTools connector could not attach because its profile was already in use, so the in-app browser supplied the checks above. Reading a comparable merged PR through gh was unavailable because api.github.com could not be reached.

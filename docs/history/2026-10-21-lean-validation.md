## Verification and corrections

The final distribution run reported:

```text
Verified 404 icons across 811 bundle cases.
Selective loading verified: shared CSS only, unused icon behavior excluded.
Verified 404 production drawings and native controls; 404 public exports have recorded drawing baselines.
```

Its five bundle negative tests, three fixture tests and three drawing-checker tests passed. The fixture tests confirmed reuse and rejection of changed inputs or modified output. Unknown icon and mechanism arguments failed before validation started. `git diff --check` passed. No production-source, fixture-page, lockfile or Playwright-configuration diff remained.

The following failures and retries are part of the evidence:

- Dependency installation failed offline and through DNS. Existing matching dependencies were reused. pnpm rejected an initial symlink for the dependency root; using a real root directory corrected that setup.
- Early server starts timed out or encountered stale locks. Locks were removed only after their recorded processes were confirmed stopped. Final workflow runs used a dedicated port.
- The bounded original family run had two page setup/closure timeouts. It did not produce a complete successful baseline. No assertion failure was observed in that run.
- An experimental all-icon page made preparation costly and was discarded. A preparation also rejected source changes during its build. The final preparation succeeded and later runs reused it.
- Pruning initially exposed missing test imports and a now-unreachable Loader branch in type checking. Those were corrected. The drawing converter was corrected to follow labels on SVG and represent square frames as rectangles.
- The initial sequential production-import smoke timed out once, after an earlier successful 2.1-second run. Imports were changed to `Promise.all` with identical assertions and timeout. A separate retry failed at server startup. The final smoke passed in both required workflows.
- The five-minute cap interrupted the first reduced-suite batch. The remaining files then passed without changing per-test deadlines.

## Remaining risks and future work rules

Static HTML does not prove painted visibility or correct animation targets. Shared representatives can miss an icon-specific selector or timing error. The removed comparison matrices no longer check catalogue-wide numerical fidelity against every upstream pose and size. Only Chrome was exercised. Manual visual acceptance remains with the user.

Use [the scope runner](../../scripts/validate.mjs) and [the validation guide](../validation.md) for current commands. An ordinary geometry edit uses `validate:icon`; a new export or fixture uses `validate:distribution`; a shared change selects its affected mechanisms. Reuse an existing representative when the mechanism is unchanged. Add a focused browser regression for a reproduced failure or a new mechanism, and connect that suite to the scope runner. These rules replace the former blanket full-catalogue validation requirement in [AGENTS.md](../../AGENTS.md) and [CONTRIBUTING.md](../../CONTRIBUTING.md).
